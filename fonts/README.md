# Fonts 目錄說明

本目錄存放用於 CrossPoint Reader 的原始 TrueType (`.ttf`) 與 OpenType (`.otf` / `.ttc`) 字型檔案。

* **偽直排（Pseudo-vertical）技術指引與跨 Up-EM 縮放對齊協定**：請參見 [GEMINI.md](./GEMINI.md)。
* **二進位字型產出目錄**：編譯完成之 `.cpfont` 存放於 `../cpfonts/`。
* **字型編譯工具**：位於 `../source/crosspoint-reader-1.6.5/lib/EpdFont/scripts/fontconvert_sdcard.py`。
